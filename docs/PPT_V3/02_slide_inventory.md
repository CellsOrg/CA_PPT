## Numbering convention

- 본편은 기존 01–25 번호를 그대로 유지한다.
- 추가 슬라이드는 기존 번호를 밀지 않는다:
  - `00` Cover — 01 앞에 추가
  - `06A` Fan Event — 06과 07 사이에 삽입 (06/07 이후 번호 불변)
  - `26` Ending — 25 뒤에 추가
  - `27` Quiz Winner / Gift Delivery — 26 뒤에 추가
- 실제 파일: `slides/slide-00.png` … `slides/slide-27.png` + `slides/slide-06A.png` (총 29장)
