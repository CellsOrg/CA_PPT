assets/ — PPT에 넣을 실제 자산을 여기에 둔다.

현재 이 폴더는 비어 있다 (repo에 확정된 브랜드 자산이 없음).
PPT 담당자가 아래를 준비해 슬라이드의 placeholder 도형과 교체한다.

필요 자산
─────────
1. 로고 / 워드마크          → 01 Cover, 21 Closing 의 [ ALPACA MASCOT + LOGO ] 박스
2. 알파카 마스코트 (PNG, 투명배경)  → 01 Cover, 07 Live Event(이벤트 안내 그래픽), 21 Closing
                                   ※ B2B(11~17)·Best Practices(18~19) 슬라이드에는 넣지 않는다
3. Salesforce 실제 스크린샷   → 08 / 13 / 16 의 [ SCREENSHOT ] 박스
                                (Fan 360·Recommendation Hub / Tableau·Lead·Account / Negotiation)
4. 데모 영상 (mp4)            → 09 / 14 의 'DEMO VIDEO 재생 영역' (PowerPoint 삽입 > 비디오)
5. LIVE 시연 화면              → 07 / 11 / 15 는 발표 중 실제 화면 전환. 백업 스크린샷만 준비
6. QR 코드                     → 07 의 QR PLACEHOLDER (destination 확정 후)
7. 차트 데이터                 → 02 의 DATA PLACEHOLDER (실측 데이터만. 임의 수치 금지)

교체 방법
─────────
PowerPoint에서 placeholder 도형을 선택 → 삭제 후 같은 자리에 이미지/영상 배치,
또는 도형 우클릭 > "도형 서식" > 채우기 > "그림 또는 질감 채우기".
