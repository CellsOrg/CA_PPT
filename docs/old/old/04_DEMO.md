# 04_DEMO.md 

전체 메시지
> 팬을 이해하는 것에 끝나지 않고, 그 데이터를 실제 매출 기회로 연결

## 🎬 B2C Demo — 「김매니저의 Game Day」

### Scene 0. 김매니저의 업무
김매니저가 Fan 360 화면을 보고 팬을 관리한다
→ **VIP 조기 갱신 대상 발견**
→ Recommendation이 대상 Fan을 추천
→ Agent가 개인화 메시지 생성
→ Manager가 확인/승인
→ Email 발송
→ “AI가 팬을 분석하는 데서 끝나는 게 아니라 실제 팬 관리 업무까지 실행합니다.”

### Scene 1. 실시간 참여 이벤트 진행
경기 진행 중 전광판에 QR 등장.
> “Cloud Alpacas Fan Event! 지금 참여해주세요 🦙”

관객이 QR → Experience Cloud → 이벤트 응모
→ 응모 데이터가 Salesforce에 들어옴
→ “우리는 팬 데이터를 사후 분석만 하는 게 아니라, 경기 중에도 새로운 팬 데이터를 만들어냅니다.”

### Scene 2. 경기 후/다음 업무 — Slack Alert 🔔
김매니저에게 Slack 알림:
> 📊 이번 달 Fan Insight가 생성되었습니다.
> 최근 3개월 신규 팬 분석 결과를 확인하세요.”

→ Fan Insight Dashboard/Report 진입
→ 20~30대 여성 신규 팬 급증 발견
→ 연령 / 성별 / Engagement / 구매 특성 확인
→ 김매니저가 깨닫는다.
> “우리 팬덤에 새로운 변화가 생겼네.”

### Scene 3. B2C의 마지막 — Insight → PRM 전달 ⭐
김매니저
> “이 팬층을 활용할 수 있는 기업을 찾아보면 좋겠다"

→ Fan Insight를 PRM/B2B 팀에 전달
→ 여기서 B2C 종료.

그리고 화면/멘트 딱 종료

> “팬을 이해하는 것에서 끝나지 않습니다.
> 이제 이 팬덤의 가치를 활용할 다음 팀으로 연결합니다.”

---
## 🎬 B2B Demo — 「이매니저의 Partnership Day」

### Scene 4. 이매니저의 업무 시작
Slack에 알림이 온다.
> 📊 김매니저로부터 Fan Insight가 전달되었습니다.
> “최근 10~30대 여성 팬의 비중과 참여도가 크게 증가했습니다.”

→ 이매니저가 Fan Insight 확인
→ 팬의 연령 / 성별 / Engagement / 구매 특성 확인
→ “이 팬덤을 원하는 브랜드가 있을까?”

### Scene 5. AI와 함께 잠재 기업 발굴
이매니저가 AI에게:
> “이 팬층과 잘 맞는 기업을 찾아줘.”

→ 후보 기업 리스트
→ Fan Fit / 브랜드 적합성 / 시너지 / 실행 가능성 확인
→ TOP 3 후보 선정


### Scene 6. 후보 기업을 영업 기회로 전환
이매니저:
> “1순위 기업과 제휴를 추진해보자.”

→ Lead / Candidate 확인
→ Account / Contact 연결
→ Opportunity 생성
→ Sponsorship Package / Collaboration 검토

### Scene 7. 제휴 제안 → Partnership으로 확장
Opportunity에서
→ 팬 인사이트 기반 제휴 제안
→ Collaboration 실행
→ 팬 반응 / 성과 확인
→ 단기 Collaboration → 장기 Partnership / Sponsorship

이매니저의 마지막 멘트:
> “팬 데이터를 보니 우리가 어떤 기업에게 가치를 제공할 수 있는지 알 수 있었습니다. 이제 이 > 기회를 장기적인 파트너십으로 만들어보겠습니다.”
